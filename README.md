# Clínica Paula Estética — Dra. Laís Paula

Landing page editorial em Next.js, React e TypeScript, personalizada a partir do template premium-vendas.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```bash
npm ci
npm run dev
```

## Vercel

Importe este repositório na Vercel usando o preset Next.js. A raiz do repositório é a raiz do projeto. Build: `npm run build`.

## Conteúdo

Os textos e registros ficam centralizados em `data/site.ts`. Como não foi fornecido um telefone, os CTAs direcionam para o Instagram da clínica. Endereço, CRO, formação e depoimentos não foram inventados.

As imagens de apresentação e resultados vieram dos anexos fornecidos. Fontes locais e licenças estão mantidas em `public/fonts`.
